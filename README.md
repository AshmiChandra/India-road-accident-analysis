# India Road Accident Analysis

## Overview
This project focuses on analyzing Indian road accident data obtained from official government sources. The dataset was cleaned, processed, and analyzed using Python to uncover patterns, trends, and insights related to road accidents across different states and categories.

---

## Objectives
- Clean and preprocess real-world government data
- Handle missing values and inconsistent formatting
- Perform Exploratory Data Analysis (EDA)
- Identify trends and patterns in accident statistics
- Create meaningful visualizations for better understanding

---

## Dataset
- Source: Official Government Portal (data.gov)
- Type: Road Accident Statistics Dataset
- Format: CSV

---

## Data Cleaning Process
The following preprocessing steps were performed:
- Removed unnecessary rows and columns
- Renamed columns for readability
- Checked and handled missing values
- Removed duplicate records
- Standardized column formats
- Converted data types where necessary

---

## Exploratory Data Analysis (EDA)
EDA was performed to:
- Compare accident cases across states
- Analyze fatalities and injuries
- Identify high-risk regions
- Understand overall accident trends

Visualizations used:
- Bar Charts
- Pie Charts
- Histograms
- Correlation Heatmaps

---

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

---

## Conclusion
This project demonstrates the process of working with real-world government datasets by cleaning, analyzing, and visualizing accident-related data to extract meaningful insights.
